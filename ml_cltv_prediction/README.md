# Customer Lifetime Value Prediction

This module predicts **Customer Lifetime Value (CLTV)** using e-commerce transactional data from the Olist dataset. It applies machine learning techniques to estimate the total revenue a customer is likely to generate over their relationship with the company.

## Goals
- Engineer features from real-world order/payment data
- Train and evaluate regression models to predict CLTV
- Understand key drivers of customer value
- (Optional) Visualize results in a Streamlit dashboard

## Skills & Tools Demonstrated
- Feature Engineering (RFM, AOV, tenure)
- Regression Modeling (Linear, Tree-based)
- Model Evaluation (MAE, RMSE, R²)
- scikit-learn, XGBoost
- Python (Pandas, NumPy)
- EDA & Visualization (Seaborn, Matplotlib)

## Files
- `cltv_modeling.ipynb` – Jupyter notebook with full pipeline
- `outputs/` – Charts, metrics, feature importances

## Data Source
- [Olist E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
